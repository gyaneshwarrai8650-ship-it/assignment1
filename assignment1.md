**<center>What happens between typing a URL and seeing the page?</center>**
'___'

When we type a URL into a web browser and press Enter, the browser first identifies the website address and uses DNS (Domain Name System) to find the IP address of the server. Then, the browser establishes a connection with the server and sends an HTTP or HTTPS request to get the webpage. The server processes the request and sends back the required files, such as HTML, CSS, JavaScript, and images. The browser reads the HTML to create the structure of the page, uses CSS to style it, and runs JavaScript to add interactive features. Finally, the browser displays the fully rendered webpage on the screen, allowing us to view and interact with it.
